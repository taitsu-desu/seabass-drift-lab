# シーバス ドリフトラボ

川の流れにルアーを乗せる「ドリフトの釣り」で、ルアーの**頭の向き**と**ターンのタイミング**が条件によってどう変わるかを、流体力学モデルで可視化するWebアプリです。

**▶ アプリを開く: https://taitsu-desu.github.io/seabass-drift-lab/**

## 変えられる条件
- 流速・川幅・流芯の位置（岸際は遅く流芯が速い流速分布）
- キャスト方向（アップ／クロス／ダウン）・飛距離・ロッドの向き
- 着水時のスラッグ量と膨らむ側、残すスラッグ量、巻き速度
- メンディング（時刻指定で上流／下流へ、ベリー量による自動メンド、返すラインの割合）
- 橋（位置・幅・水中の橋脚の本数と太さ）と明暗（橋の影／常夜灯、明るい側）
- ルアー（フローティングミノー／シンキングペンシル／バイブレーション）

タックルは **PE 1号（φ0.165mm）＋ フロロカーボン 4号（φ0.33mm）1.2m** を想定しています。

## モデル
- 川を真上から見た2D。ラインは約0.8m間隔の節点の鎖で、伸びないが緩むロープとして Position Based Dynamics で解いています（dt = 5ms）。
- ラインの抵抗はモリソン式で、直角方向（C_N≈1.2）と接線方向（表面摩擦 C_f≈0.015）に分けて計算します。
- ルアーは異方性の抗力を持つ剛体です。頭の向きは、相対流への風見鶏安定とアイにかかるライン張力のトルクで決まります。
- 頭の向きが下流寄りから上流寄りへ90°を越えた瞬間を「ターン」として記録します。
- 橋脚は円柱まわりのポテンシャル流れと伴流で流れ場を変えます。ラインは橋脚に巻き付き、接触を記録します。
- 明暗は水面の光量で表し、ルアーが暗部へ入った瞬間の頭の向きと入り方を記録します（`#bridge` 付きURLで橋の明暗プリセットを開けます）。

上下方向（空中のライン・沈下・風）、乱流やヨレ、ロッドワークは省略しています。数値は傾向をつかむための目安です。

## ファイル
- `sim.js` 物理シミュレーション本体（ブラウザ／Node 両対応）
- `worker.js` Web Worker で計算
- `app.js` 描画と操作
- `index.html` ページ

ビルド不要の静的サイトです。ローカルでは `python3 -m http.server` などで配信して開いてください。
